Scheduled jobs

Run these from cron (or your host's scheduler):

python manage.py night_audit          # daily ~23:30
python manage.py expire_holds         # every 5 minutes
python manage.py mpesa_check_pending  # every 2 minutes

The system also does these lazily when staff or guests use it, so nothing breaks if cron is missing.
